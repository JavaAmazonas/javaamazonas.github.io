## تعاون کریں

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas ویب ایک اوپن سورس پراجیکٹ ہے۔ ہم مکمل طور پر شفاف ترقیاتی عمل کے لیے پرعزم ہیں اور کسی بھی قسم کے تعاون کی بے حد قدر کرتے ہیں۔ چاہے آپ ہمیں بگز درست کرنے میں مدد دیں، نئے فیچرز تجویز کریں، ہماری دستاویزات کو بہتر بنائیں، یا محض اس پراجیکٹ کا تعارف دوسروں تک پہنچائیں، ہمیں آپ کو Java Amazonas کمیونٹی کا حصہ بنا کر بے حد خوشی ہوگی۔ ہم مستقبل میں ایک بلاگ شروع کرنے کا بھی ارادہ رکھتے ہیں۔

- بگ رپورٹ: اگر سائٹ استعمال کرتے ہوئے آپ کو کوئی خرابی کا پیغام نظر آئے یا کسی مسئلے کا سامنا ہو تو براہ کرم [ایک بگ رپورٹ درج کریں](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- فیچر کی درخواست: اگر آپ کے پاس کوئی خیال ہے یا کوئی ایسی چیز ہے جس کی کمی ترقیاتی عمل کو آسان اور مضبوط بنا سکتی ہے تو براہ کرم [ایک فیچر کی درخواست جمع کروائیں](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).
