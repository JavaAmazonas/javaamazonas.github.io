## Prispievanie

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web je open-source projekt. Snažíme sa o plne transparentný proces vývoja a veľmi si vážime akýkoľvek príspevok. Či už nám pomáhate opravovať chyby, navrhujete nové funkcie, vylepšujete našu dokumentáciu, alebo len šírite dobré meno projektu, radi by sme vás privítali ako súčasť komunity Java Amazonas. V budúcnosti tiež plánujeme vytvoriť blog.

- Nahlásenie chyby: Ak sa vám zobrazí chybové hlásenie alebo narazíte na problém pri používaní stránky, vytvorte [hlásenie o chybe](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Žiadosť o funkciu: Ak máte nápad, alebo si myslíte, že niečo chýba a uľahčilo by to a spevnilo vývoj, odošlite [žiadosť o funkciu](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Neviete, kde začať? Pridajte sa na náš Discord a radi vám pomôžeme začať!
