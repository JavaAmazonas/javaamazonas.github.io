## યોગદાન

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas વેબસાઇટ એક ઓપન-સોર્સ પ્રોજેક્ટ છે. અમે સંપૂર્ણપણે પારદર્શક વિકાસ પ્રક્રિયા પ્રત્યે પ્રતિબદ્ધ છીએ અને દરેક યોગદાનની ખૂબ કદર કરીએ છીએ. ભલે તમે અમને બગ્સ સુધારવામાં મદદ કરો, નવી સુવિધાઓ સૂચવો, અમારા દસ્તાવેજીકરણમાં સુધારો કરો, અથવા ફક્ત આ પ્રોજેક્ટ વિશે અન્ય લોકોને જણાવો, અમે તમને Java Amazonas સમુદાયના ભાગરૂપે જોવા આતુર છીએ. ભવિષ્યમાં અમે એક બ્લોગ પણ શરૂ કરવાનું આયોજન કરી રહ્યા છીએ.

- બગ રિપોર્ટ: જો સાઇટનો ઉપયોગ કરતી વખતે તમને કોઈ એરર મેસેજ દેખાય અથવા કોઈ સમસ્યાનો સામનો કરવો પડે, તો એક [બગ રિપોર્ટ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+) બનાવો.

- ફીચર રિક્વેસ્ટ: જો તમારી પાસે કોઈ વિચાર છે અથવા કંઈક ખૂટે છે જે વિકાસને સરળ અને વધુ મજબૂત બનાવી શકે, તો એક [ફીચર રિક્વેસ્ટ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) સબમિટ કરો.

ક્યાંથી શરૂઆત કરવી તે ખબર નથી? અમારા Discord પર જોડાઓ, અમે તમને શરૂ કરવામાં મદદ કરીશું!
