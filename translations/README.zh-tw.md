## 貢獻指南

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas 網站是一個開源專案。我們致力於維持完全透明的開發流程，並非常感謝任何形式的貢獻。無論您是協助我們修復錯誤、提出新功能建議、改善文件內容，還是幫忙宣傳，我們都很樂意邀請您成為 Java Amazonas 社群的一份子。未來我們也計劃建立部落格。

- 錯誤回報：如果您在使用網站時看到錯誤訊息或遇到問題，請建立一份 [錯誤回報](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- 功能需求：如果您有任何想法，或覺得缺少某項功能會讓開發更容易、更穩健，歡迎提交 [功能需求](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

不知道從何開始嗎？歡迎加入我們的 Discord，我們會協助您踏出第一步！
