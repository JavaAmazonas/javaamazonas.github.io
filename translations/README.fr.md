## Contribuer

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web est un projet open source. Nous nous engageons à mener un processus de développement entièrement transparent et nous apprécions énormément toute contribution. Que vous nous aidiez à corriger des bugs, que vous proposiez de nouvelles fonctionnalités, que vous amélioriez notre documentation ou que vous fassiez simplement connaître le projet, nous serions ravis de vous compter parmi la communauté Java Amazonas. Nous prévoyons également de créer un blog à l'avenir.

- Signalement de bug : Si vous voyez un message d'erreur ou rencontrez un problème en utilisant le site, créez un [rapport de bug](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Demande de fonctionnalité : Si vous avez une idée ou s'il manque quelque chose qui rendrait le développement plus simple et plus robuste, soumettez une [demande de fonctionnalité](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Vous ne savez pas par où commencer ? Rejoignez notre Discord, nous vous aiderons à démarrer !
