## Közreműködés

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

A Java Amazonas web egy nyílt forráskódú projekt. Elkötelezettek vagyunk a teljesen átlátható fejlesztési folyamat mellett, és nagyra értékelünk minden hozzájárulást. Legyen szó hibajavításról, új funkciók javaslásáról, a dokumentációnk fejlesztéséről vagy csak arról, hogy másoknak is mesélsz rólunk, szívesen látunk a Java Amazonas közösség tagjaként. A jövőben egy blog létrehozását is tervezzük.

- Hibabejelentés: Ha hibaüzenetet látsz, vagy problémába ütközöl az oldal használata közben, hozz létre egy [hibabejelentést](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Funkciókérés: Ha van egy ötleted, vagy hiányzik valami, ami könnyebbé és stabilabbá tenné a fejlesztést, küldj be egy [funkciókérést](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nem tudod, hol kezdd? Csatlakozz a Discord szerverünkhöz, és segítünk elindulni!
