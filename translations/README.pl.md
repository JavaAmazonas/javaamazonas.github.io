## Współtworzenie

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web to projekt open source. Dążymy do w pełni przejrzystego procesu rozwoju i bardzo doceniamy każdy wkład. Niezależnie od tego, czy pomagasz nam naprawiać błędy, proponujesz nowe funkcje, ulepszasz naszą dokumentację, czy po prostu rozpowszechniasz informacje o projekcie, z przyjemnością powitamy Cię jako część społeczności Java Amazonas. Planujemy również w przyszłości uruchomić bloga.

- Zgłoszenie błędu: Jeśli zobaczysz komunikat o błędzie lub napotkasz problem podczas korzystania ze strony, utwórz [zgłoszenie błędu](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Prośba o nową funkcję: Jeśli masz pomysł albo brakuje czegoś, co ułatwiłoby i usprawniło rozwój projektu, prześlij [prośbę o nową funkcję](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nie wiesz, od czego zacząć? Dołącz do naszego Discorda, a pomożemy Ci ruszyć z miejsca!
