## Bidra

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas webb är ett open source-projekt. Vi strävar efter en helt transparent utvecklingsprocess och uppskattar verkligen alla bidrag. Oavsett om du hjälper oss att fixa buggar, föreslår nya funktioner, förbättrar vår dokumentation eller sprider ordet, skulle vi gärna se dig som en del av Java Amazonas-gemenskapen. Vi planerar också att skapa en blogg i framtiden.

- Buggrapport: Om du ser ett felmeddelande eller stöter på ett problem när du använder webbplatsen, skapa en [buggrapport](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Funktionsförfrågan: Om du har en idé eller tycker att något saknas som skulle göra utvecklingen enklare och mer robust, skicka in en [funktionsförfrågan](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Osäker på var du ska börja? Gå med i vår Discord så hjälper vi dig igång!
