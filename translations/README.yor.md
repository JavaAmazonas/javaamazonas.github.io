## Ìdásí

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web jẹ́ iṣẹ́ akanṣe orísun-ìṣí (open-source). A ti fi ara wa jì láti tẹ̀lé ìlànà ìdàgbàsókè tí ó ṣe kedere ní kíkún, a sì mọyì ìdásí èyíkéyìí gidigidi. Yálà o ń ràn wá lọ́wọ́ láti ṣàtúnṣe àṣìṣe, o dábàá àwọn ẹ̀yà tuntun, o mú àwọn ìwé àkọsílẹ̀ wa sunwọ̀n sí i, tàbí kàn kí o máa tàn kalẹ̀ ọ̀rọ̀ nípa iṣẹ́ yìí, a yóò yọ̀ láti fi ọ́ ka apá kan àwùjọ Java Amazonas. A tún ní ètò láti dá bulọ́ọ̀gì kan sílẹ̀ ní ọjọ́ iwájú.

- Ìròyìn Àṣìṣe: Bí o bá rí ìránṣẹ́ àṣìṣe kan tàbí bí o bá pàdé ìṣòro kan nígbà tí o ń lo ojú òpó wẹ́ẹ̀bù náà, ṣẹ̀dá [ìròyìn àṣìṣe](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+) kan.

- Ìbéèrè Ẹ̀yà Tuntun: Bí o bá ní èrò kan tàbí bí ohunkóhun bá ń dánù tí yóò mú kí ìdàgbàsókè rọrùn àti lágbára sí i, fi [ìbéèrè ẹ̀yà tuntun](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) ránṣẹ́.

Ò ò dá ọ lójú ibi tí o ó ti bẹ̀rẹ̀? Dara pọ̀ mọ́ Discord wa, a óò sì ràn ọ́ lọ́wọ́ láti bẹ̀rẹ̀!
