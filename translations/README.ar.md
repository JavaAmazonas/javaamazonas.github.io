## المساهمة

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

موقع Java Amazonas هو مشروع مفتوح المصدر. نحن ملتزمون بعملية تطوير شفافة تمامًا، ونقدّر أي مساهمة تقدّمونها لنا كل التقدير. سواء كنتم تساعدوننا في إصلاح الأخطاء، أو تقترحون ميزات جديدة، أو تحسّنون توثيقنا، أو تنشرون الكلمة عنا، يسعدنا جدًا أن تكونوا جزءًا من مجتمع Java Amazonas. كما نخطط مستقبلًا لإنشاء مدونة.

- الإبلاغ عن خطأ: إذا شاهدت رسالة خطأ أو واجهت مشكلة أثناء استخدام الموقع، يُرجى إنشاء [تقرير خطأ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- طلب ميزة: إذا كانت لديك فكرة أو شعرت أن هناك شيئًا ناقصًا من شأنه أن يجعل التطوير أسهل وأكثر قوة، يُرجى تقديم [طلب ميزة](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

لست متأكدًا من أين تبدأ؟ انضم إلى Discord الخاص بنا وسنساعدك على البدء!
