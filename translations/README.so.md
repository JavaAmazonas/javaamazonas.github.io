## Ka Qeybgalka

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas waa mashruuc koodhkiisu furan yahay (open-source). Waxaan u heellan nahay hab horumarineed si buuxda u caddaan ah, waxaanan aad u qiimeynaa wax kasta oo aad naga caawiso. Hadday tahay inaad naga caawiso hagaajinta cilladaha, inaad soo jeediso astaamo cusub, inaad hagaajiso dukumentiyadeenna, ama inaad ka hadasho bulshadeenna, waxaan jeclaan lahayn inaad ka mid noqoto bulshada Java Amazonas. Waxaan sidoo kale qorsheyneynaa inaan mustaqbalka abuurno blog.

- Warbixinta Cillad: Haddii aad aragto fariin khalad ah ama aad la kulanto dhibaato adigoo isticmaalaya boggan, samee [warbixin cillad](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Codsiga Sifayn: Haddii aad qabto fikrad ama ay jirto wax maqan oo ka dhigi kara horumarinta mid fudud oo adkaysan kara, soo gudbi [codsiga sifayn](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Ma hubtid meesha aad ka bilaabayso? Ku biir Discord-kayaga, waanan kaa caawin doonaa inaad bilowdo!
