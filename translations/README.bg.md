## Как да допринесете

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web е проект с отворен код. Ние сме отдадени на напълно прозрачен процес на разработка и високо ценим всеки принос. Независимо дали ни помагате да коригираме грешки, предлагате нови функционалности, подобрявате документацията ни или просто разказвате на другите за проекта, с удоволствие бихме ви приветствали като част от общността на Java Amazonas. В бъдеще планираме да създадем и блог.

- Сигнал за грешка: Ако видите съобщение за грешка или се сблъскате с проблем при използване на сайта, създайте [сигнал за грешка](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Заявка за функционалност: Ако имате идея или забележите, че липсва нещо, което би направило разработката по-лесна и по-стабилна, изпратете [заявка за функционалност](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Не сте сигурни откъде да започнете? Присъединете се към нашия Discord и ще ви помогнем да започнете!
