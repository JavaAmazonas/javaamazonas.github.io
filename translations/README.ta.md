## பங்களிப்பு

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas வலைத்தளம் ஒரு திறந்த மூலத் திட்டமாகும். முழுமையாக வெளிப்படையான வளர்ச்சிச் செயல்முறையைப் பின்பற்ற நாங்கள் உறுதிபூண்டுள்ளோம், மேலும் எந்தவொரு பங்களிப்பையும் மனமுவந்து வரவேற்கிறோம். நீங்கள் பிழைகளைச் சரிசெய்ய உதவினாலும், புதிய அம்சங்களை முன்மொழிந்தாலும், எங்கள் ஆவணங்களை மேம்படுத்தினாலும், அல்லது இதைப் பற்றி மற்றவர்களுக்குத் தெரிவித்தாலும், நீங்கள் Java Amazonas சமூகத்தின் ஒரு பகுதியாக இருக்க வேண்டும் என்பதே எங்கள் விருப்பம். எதிர்காலத்தில் ஒரு வலைப்பதிவையும் உருவாக்கத் திட்டமிட்டுள்ளோம்.

- பிழை அறிக்கை: தளத்தைப் பயன்படுத்தும்போது பிழைச் செய்தி தென்பட்டால் அல்லது சிக்கலை எதிர்கொண்டால், [பிழை அறிக்கையை உருவாக்கவும்](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- அம்சக் கோரிக்கை: மேம்பாட்டை எளிதாகவும் வலுவாகவும் மாற்றக்கூடிய ஒரு யோசனை உங்களிடம் இருந்தால் அல்லது ஏதேனும் குறை இருந்தால், [அம்சக் கோரிக்கையை சமர்ப்பிக்கவும்](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

எங்கிருந்து தொடங்குவது எனத் தெரியவில்லையா? எங்கள் Discord-இல் இணையுங்கள், நாங்கள் உங்களுக்கு உதவுவோம்!
