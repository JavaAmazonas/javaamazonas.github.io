## സംഭാവന ചെയ്യൽ

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas വെബ്സൈറ്റ് ഒരു ഓപ്പൺ സോഴ്സ് പ്രോജക്ടാണ്. പൂർണ്ണമായും സുതാര്യമായ ഒരു വികസന പ്രക്രിയയിൽ പ്രതിജ്ഞാബദ്ധരാണ് ഞങ്ങൾ, കൂടാതെ ഏതൊരു സംഭാവനയെയും ഞങ്ങൾ ഏറെ വിലമതിക്കുന്നു. ബഗുകൾ പരിഹരിക്കാൻ സഹായിച്ചാലും, പുതിയ ഫീച്ചറുകൾ നിർദ്ദേശിച്ചാലും, ഞങ്ങളുടെ ഡോക്യുമെന്റേഷൻ മെച്ചപ്പെടുത്തിയാലും, അല്ലെങ്കിൽ ഇതിനെക്കുറിച്ച് മറ്റുള്ളവരോട് പറഞ്ഞാലും — നിങ്ങൾ Java Amazonas കമ്മ്യൂണിറ്റിയുടെ ഭാഗമാകുന്നത് ഞങ്ങൾക്ക് സന്തോഷമുള്ള കാര്യമാണ്. ഭാവിയിൽ ഒരു ബ്ലോഗ് ആരംഭിക്കാനും ഞങ്ങൾ പദ്ധതിയിടുന്നു.

- ബഗ് റിപ്പോർട്ട്: സൈറ്റ് ഉപയോഗിക്കുമ്പോൾ ഒരു എറർ മെസേജ് കണ്ടാലോ, എന്തെങ്കിലും പ്രശ്നം നേരിട്ടാലോ, ഒരു [ബഗ് റിപ്പോർട്ട്](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+) സൃഷ്ടിക്കുക.

- ഫീച്ചർ റിക്വസ്റ്റ്: വികസനം എളുപ്പവും കൂടുതൽ ശക്തവുമാക്കാൻ കഴിയുന്ന ഒരു ആശയമുണ്ടെങ്കിലോ, എന്തെങ്കിലും കുറവുണ്ടെന്ന് തോന്നിയാലോ, ഒരു [ഫീച്ചർ റിക്വസ്റ്റ്](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) സമർപ്പിക്കുക.

എവിടെ നിന്ന് തുടങ്ങണമെന്ന് ഉറപ്പില്ലേ? ഞങ്ങളുടെ Discord-ൽ ചേരൂ, ഞങ്ങൾ നിങ്ങളെ സഹായിക്കാം!
