## การมีส่วนร่วม

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web เป็นโปรเจกต์โอเพนซอร์ส เรามุ่งมั่นที่จะดำเนินกระบวนการพัฒนาอย่างโปร่งใสอย่างเต็มที่ และยินดีรับทุกการมีส่วนร่วมเป็นอย่างยิ่ง ไม่ว่าคุณจะช่วยเราแก้ไขบั๊ก เสนอฟีเจอร์ใหม่ ปรับปรุงเอกสารประกอบ หรือช่วยบอกต่อ เราก็ยินดีต้อนรับให้คุณเป็นส่วนหนึ่งของชุมชน Java Amazonas นอกจากนี้เรายังวางแผนที่จะสร้างบล็อกในอนาคตอีกด้วย

- รายงานบั๊ก: หากคุณพบข้อความแสดงข้อผิดพลาดหรือเจอปัญหาขณะใช้งานเว็บไซต์ ให้สร้าง [รายงานบั๊ก](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- ขอฟีเจอร์ใหม่: หากคุณมีไอเดียหรือคิดว่ายังขาดอะไรบางอย่างที่จะช่วยให้การพัฒนาง่ายและมั่นคงยิ่งขึ้น กรุณาส่ง [คำขอฟีเจอร์](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

ไม่แน่ใจว่าจะเริ่มจากตรงไหน? เข้าร่วม Discord ของเราแล้วเราจะช่วยให้คุณเริ่มต้นได้!
