## योगदान

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas वेबसाइट हा एक मुक्त-स्रोत (ओपन-सोर्स) प्रकल्प आहे. आम्ही पूर्णतः पारदर्शक विकास प्रक्रियेसाठी वचनबद्ध आहोत आणि कोणत्याही प्रकारच्या योगदानाचे मनापासून स्वागत करतो. तुम्ही आम्हाला बग दुरुस्त करण्यात मदत करा, नवीन वैशिष्ट्ये सुचवा, आमचे दस्तऐवजीकरण सुधारित करा, किंवा फक्त या प्रकल्पाबद्दल इतरांना सांगा — तुम्ही Java Amazonas समुदायाचा भाग असावा असे आम्हाला मनापासून वाटते. भविष्यात आम्ही एक ब्लॉग सुरू करण्याचीही योजना आखत आहोत.

- बग रिपोर्ट: साइट वापरताना जर तुम्हाला एरर मेसेज दिसला किंवा एखादी समस्या आली, तर एक [बग रिपोर्ट](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+) तयार करा.

- फीचर रिक्वेस्ट: तुमच्याकडे एखादी कल्पना असेल किंवा विकासाला सोपे आणि अधिक भक्कम बनवणारे काही अपुरे वाटत असेल, तर एक [फीचर रिक्वेस्ट](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) सबमिट करा.

कुठून सुरुवात करावी हे समजत नाही? आमच्या Discord मध्ये सामील व्हा, आम्ही तुम्हाला मदत करू!
