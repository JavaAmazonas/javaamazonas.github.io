## Bydraes

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web is 'n oopbron-projek. Ons streef na 'n volledig deursigtige ontwikkelingsproses en waardeer enige bydrae opreg. Of jy ons nou help om foute reg te stel, nuwe funksies voorstel, ons dokumentasie verbeter, of net die woord versprei, ons sal dit waardeer om jou deel van die Java Amazonas-gemeenskap te maak. Ons beplan ook om in die toekoms 'n blog te skep.

- Foutverslag: As jy 'n foutboodskap sien of 'n probleem teëkom terwyl jy die webwerf gebruik, skep 'n [foutverslag](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Funksieversoek: As jy 'n idee het, of iets ontbreek wat ontwikkeling makliker en meer robuust sou maak, dien 'n [funksieversoek](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) in.

Weet jy nie waar om te begin nie? Sluit aan by ons Discord en ons sal jou help om te begin!
