## Kā iesaistīties

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web ir atvērtā pirmkoda projekts. Mēs esam apņēmušies nodrošināt pilnībā caurspīdīgu izstrādes procesu un ļoti novērtējam jebkuru ieguldījumu. Neatkarīgi no tā, vai palīdzi mums labot kļūdas, piedāvā jaunas funkcijas, uzlabo mūsu dokumentāciju vai vienkārši izplati ziņu par projektu, mēs priecāsimies redzēt tevi kā Java Amazonas kopienas daļu. Nākotnē plānojam izveidot arī emuāru (blog).

- Kļūdas ziņojums: Ja pamani kļūdas paziņojumu vai saskaries ar problēmu, izmantojot vietni, izveido [kļūdas ziņojumu](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Funkcijas pieprasījums: Ja tev ir ideja vai pietrūkst kaut kā, kas padarītu izstrādi vieglāku un uzticamāku, iesniedz [funkcijas pieprasījumu](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nezini, no kā sākt? Pievienojies mūsu Discord serverim, un mēs palīdzēsim tev sākt!
