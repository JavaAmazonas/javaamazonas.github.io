## Contribuții

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Site-ul Java Amazonas este un proiect open-source. Ne-am angajat să menținem un proces de dezvoltare complet transparent și apreciem enorm orice contribuție. Fie că ne ajuți să reparăm erori, propui funcționalități noi, îmbunătățești documentația noastră sau pur și simplu răspândești vestea despre noi, ne-ar face plăcere să te avem alături în comunitatea Java Amazonas. De asemenea, plănuim să creăm un blog în viitor.

- Raport de eroare: Dacă vezi un mesaj de eroare sau întâmpini o problemă în timp ce folosești site-ul, creează un [raport de eroare](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Cerere de funcționalitate: Dacă ai o idee sau lipsește ceva ce ar face dezvoltarea mai ușoară și mai robustă, trimite o [cerere de funcționalitate](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nu știi de unde să începi? Alătură-te serverului nostru de Discord și te vom ajuta să pornești!
