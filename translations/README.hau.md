## Ba da Gudummawa

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas yanar gizo aikin buɗaɗɗen tushe ne (open-source). Mun sadaukar da kanmu ga tsarin ci gaba mai cikakken gaskiya kuma muna godiya matuƙa da kowace gudummawa. Ko kana taimaka mana wajen gyara kurakurai, ba da shawarar sabbin fasaloli, inganta takardunmu, ko yaɗa labarin aikin, za mu yi farin ciki da samun ka a matsayin wani ɓangare na al'ummar Java Amazonas. Muna kuma da shirin kafa shafin yanar gizo na labarai (blog) a nan gaba.

- Rahoton Kwaro: Idan ka ga saƙon kuskure ko ka fuskanci matsala yayin amfani da shafin, ka ƙirƙiri [rahoton kwaro](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Neman Sabon Fasali: Idan kana da wani ra'ayi ko akwai wani abu da ya ɓace wanda zai sauƙaƙa kuma ya ƙarfafa ci gaban aikin, ka aika [neman sabon fasali](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Ba ka da tabbacin inda za ka fara? Shiga Discord ɗinmu kuma za mu taimaka maka fara!
