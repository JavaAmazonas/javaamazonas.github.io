## Kontribuo

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web është një projekt me burim të hapur. Ne jemi të përkushtuar ndaj një procesi zhvillimi plotësisht transparent dhe vlerësojmë shumë çdo kontribut. Nëse na ndihmoni të rregullojmë gabime, propozoni veçori të reja, përmirësoni dokumentacionin tonë, ose thjesht e përhapni fjalën për ne, do të donim shumë t'ju kishim si pjesë të komunitetit Java Amazonas. Gjithashtu planifikojmë të krijojmë një blog në të ardhmen.

- Raportim Gabimi: Nëse shihni një mesazh gabimi ose hasni një problem gjatë përdorimit të faqes, krijoni një [raport gabimi](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Kërkesë për Veçori: Nëse keni një ide ose diçka mungon që do ta bënte zhvillimin më të lehtë dhe më të fortë, dërgoni një [kërkesë për veçori](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nuk jeni të sigurt nga ku të filloni? Bashkohuni me Discord-in tonë dhe do t'ju ndihmojmë të filloni!
