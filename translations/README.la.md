## ການປະກອບສ່ວນ

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web ເປັນໂຄງການ open-source. ພວກເຮົາມຸ່ງໝັ້ນຕໍ່ຂະບວນການພັດທະນາທີ່ໂປ່ງໃສຢ່າງເຕັມທີ່ ແລະ ຂອບໃຈຢ່າງສູງຕໍ່ທຸກການປະກອບສ່ວນ. ບໍ່ວ່າທ່ານຈະຊ່ວຍພວກເຮົາແກ້ໄຂຂໍ້ຜິດພາດ, ສະເໜີຄຸນສົມບັດໃໝ່, ປັບປຸງເອກະສານຂອງພວກເຮົາ, ຫຼືຊ່ວຍເຜີຍແຜ່ຂ່າວສານ, ພວກເຮົາຢາກໃຫ້ທ່ານເປັນສ່ວນໜຶ່ງຂອງຊຸມຊົນ Java Amazonas. ພວກເຮົາຍັງມີແຜນທີ່ຈະສ້າງບລັອກໃນອະນາຄົດອີກດ້ວຍ.

- ລາຍງານຂໍ້ຜິດພາດ: ຖ້າທ່ານເຫັນຂໍ້ຄວາມແຈ້ງຂໍ້ຜິດພາດ ຫຼືພົບບັນຫາໃນຂະນະໃຊ້ເວັບໄຊທ໌, ໃຫ້ສ້າງ [ລາຍງານຂໍ້ຜິດພາດ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- ຄຳຂໍຄຸນສົມບັດ: ຖ້າທ່ານມີໄອເດຍ ຫຼືມີບາງຢ່າງທີ່ຂາດຫາຍໄປເຊິ່ງຈະເຮັດໃຫ້ການພັດທະນາງ່າຍຂຶ້ນ ແລະ ໜັກແໜ້ນຂຶ້ນ, ໃຫ້ສົ່ງ [ຄຳຂໍຄຸນສົມບັດ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

ບໍ່ແນ່ໃຈວ່າຈະເລີ່ມຈາກໃສ? ເຂົ້າຮ່ວມ Discord ຂອງພວກເຮົາ ແລ້ວພວກເຮົາຈະຊ່ວຍທ່ານເລີ່ມຕົ້ນ!
