## Menyumbang

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web adalah projek sumber terbuka. Kami komited kepada proses pembangunan yang telus sepenuhnya dan amat menghargai sebarang sumbangan. Sama ada anda membantu kami membaiki pepijat, mencadangkan ciri baharu, menambah baik dokumentasi kami, atau menyebarkan berita tentang projek ini, kami amat mengalu-alukan anda sebagai sebahagian daripada komuniti Java Amazonas. Kami juga merancang untuk mewujudkan blog pada masa hadapan.

- Laporan Pepijat: Jika anda melihat mesej ralat atau menghadapi masalah semasa menggunakan laman ini, sila buat [laporan pepijat](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Permintaan Ciri: Jika anda mempunyai idea atau sesuatu yang tiada namun boleh menjadikan pembangunan lebih mudah dan mantap, hantarkan [permintaan ciri](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Tidak pasti dari mana hendak bermula? Sertai Discord kami dan kami akan bantu anda bermula!
