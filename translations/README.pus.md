## مرسته

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas ویبپاڼه یو خلاص سرچینه پروژه ده. موږ ژمن یو چې د پراختیا بشپړ روڼ بهیر ولرو او د هرې مرستې لپاره ډېره مننه کوو. که تاسو زموږ سره د تېروتنو په سمولو کې مرسته کوئ، نوي ځانګړتیاوې وړاندې کوئ، زموږ اسناد ښه کوئ، یا یې د نورو سره شریکوئ، موږ به ډېر خوښ شو چې تاسو د Java Amazonas ټولنې برخه شئ. موږ همدارنګه پلان لرو چې راتلونکي کې یو بلاګ هم جوړ کړو.

- د تېروتنې راپور: که تاسو د سایټ کارولو پر مهال د تېروتنې پیغام وګورئ یا له کوم ستونزې سره مخ شئ، مهرباني وکړئ [د تېروتنې راپور جوړ کړئ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- د ځانګړتیا غوښتنه: که تاسو کومه نظر لرئ یا یو څه ونه وي چې پراختیا به یې اسانه او پیاوړې کړي، مهرباني وکړئ [د ځانګړتیا غوښتنه وسپارئ](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

نه پوهېږئ چې له کوم ځایه پیل وکړئ؟ زموږ ډیسکارډ سره یوځای شئ، موږ به تاسو سره د پیل کولو لپاره مرسته وکړو!
