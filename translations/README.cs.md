## Jak přispět

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web je open-source projekt. Jsme odhodláni udržovat plně transparentní proces vývoje a velmi si vážíme jakéhokoli příspěvku. Ať už nám pomáháte opravovat chyby, navrhujete nové funkce, vylepšujete naši dokumentaci, nebo o nás jen šíříte povědomí, rádi vás přivítáme jako součást komunity Java Amazonas. Do budoucna také plánujeme vytvořit blog.

- Hlášení chyby: Pokud narazíte na chybové hlášení nebo problém při používání webu, vytvořte [hlášení chyby](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Žádost o funkci: Pokud máte nápad, nebo vám něco chybí a mohlo by to usnadnit a zlepšit vývoj, odešlete [žádost o funkci](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nevíte, kde začít? Připojte se k našemu Discordu a rádi vám pomůžeme začít!
