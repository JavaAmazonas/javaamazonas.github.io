## Sodelovanje

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web je odprtokodni projekt. Zavezani smo popolnoma preglednemu razvojnemu procesu in zelo cenimo vsak prispevek. Ne glede na to, ali nam pomagate odpravljati napake, predlagate nove funkcionalnosti, izboljšujete našo dokumentacijo ali le širite glas o nas, bi vas z veseljem sprejeli kot del skupnosti Java Amazonas. V prihodnosti nameravamo ustvariti tudi blog.

- Prijava napake: Če opazite sporočilo o napaki ali naletite na težavo pri uporabi strani, ustvarite [prijavo napake](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Predlog funkcionalnosti: Če imate zamisel ali menite, da nekaj manjka in bi olajšalo ter okrepilo razvoj, oddajte [predlog funkcionalnosti](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Ne veste, kje začeti? Pridružite se našemu Discordu in pomagali vam bomo začeti!
