## Συνεισφορά

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Το Java Amazonas web είναι ένα έργο ανοιχτού κώδικα. Είμαστε αφοσιωμένοι σε μια εντελώς διαφανή διαδικασία ανάπτυξης και εκτιμούμε βαθιά κάθε συνεισφορά. Είτε μας βοηθάτε να διορθώσουμε σφάλματα, είτε προτείνετε νέες λειτουργίες, είτε βελτιώνετε την τεκμηρίωσή μας, είτε απλώς διαδίδετε το μήνυμα, θα χαρούμε πολύ να σας έχουμε ως μέλος της κοινότητας Java Amazonas. Σχεδιάζουμε επίσης να δημιουργήσουμε ένα blog στο μέλλον.

- Αναφορά σφάλματος: Αν δείτε ένα μήνυμα σφάλματος ή αντιμετωπίσετε κάποιο πρόβλημα κατά τη χρήση του ιστότοπου, δημιουργήστε μια [αναφορά σφάλματος](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Αίτημα λειτουργίας: Αν έχετε μια ιδέα ή αν λείπει κάτι που θα έκανε την ανάπτυξη πιο εύκολη και πιο ισχυρή, υποβάλετε ένα [αίτημα λειτουργίας](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Δεν είστε σίγουροι από πού να ξεκινήσετε; Ελάτε στο Discord μας και θα σας βοηθήσουμε να ξεκινήσετε!
