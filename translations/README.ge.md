## წვლილის შეტანა

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web ღია კოდის პროექტია. ჩვენ ვართ ერთგულნი სრულიად გამჭვირვალე განვითარების პროცესის მიმართ და დიდად ვაფასებთ ნებისმიერ წვლილს. მიუხედავად იმისა, გვეხმარებით შეცდომების გამოსწორებაში, გვთავაზობთ ახალ ფუნქციებს, აუმჯობესებთ ჩვენს დოკუმენტაციას თუ უბრალოდ ავრცელებთ ინფორმაციას ჩვენს შესახებ, სიამოვნებით მიგიღებთ Java Amazonas საზოგადოების წევრად. ასევე ვგეგმავთ მომავალში ბლოგის შექმნას.

- შეცდომის შეტყობინება: თუ ხედავთ შეცდომის შეტყობინებას ან წააწყდით პრობლემას საიტის გამოყენებისას, შექმენით [შეცდომის შეტყობინება](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- ფუნქციის მოთხოვნა: თუ გაქვთ იდეა ან აკლია რაიმე, რაც განვითარებას გახდიდა უფრო მარტივს და მდგრადს, გამოაგზავნეთ [ფუნქციის მოთხოვნა](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).
