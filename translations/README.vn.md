## Đóng góp

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web là một dự án mã nguồn mở. Chúng tôi cam kết theo đuổi quy trình phát triển hoàn toàn minh bạch và trân trọng mọi đóng góp. Dù bạn giúp chúng tôi sửa lỗi, đề xuất tính năng mới, cải thiện tài liệu, hay chỉ đơn giản là lan tỏa thông tin về dự án, chúng tôi đều rất vui khi có bạn đồng hành cùng cộng đồng Java Amazonas. Chúng tôi cũng dự định xây dựng một blog trong tương lai.

- Báo lỗi: Nếu bạn thấy thông báo lỗi hoặc gặp sự cố khi sử dụng trang web, hãy tạo một [báo cáo lỗi](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Đề xuất tính năng: Nếu bạn có ý tưởng hoặc nhận thấy còn thiếu điều gì đó giúp việc phát triển dễ dàng và vững chắc hơn, hãy gửi một [yêu cầu tính năng](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Chưa biết bắt đầu từ đâu? Hãy tham gia Discord của chúng tôi, chúng tôi sẽ giúp bạn khởi đầu!
