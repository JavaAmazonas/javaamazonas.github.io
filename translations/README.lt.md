## Prisidėjimas

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

„Java Amazonas“ svetainė yra atvirojo kodo projektas. Esame įsipareigoję laikytis visiškai skaidraus plėtros proceso ir labai vertiname bet kokį indėlį. Nesvarbu, ar padedate taisyti klaidas, siūlote naujas funkcijas, tobulinate mūsų dokumentaciją, ar tiesiog papasakojate apie mus kitiems – mielai priimtume jus į „Java Amazonas“ bendruomenę. Ateityje taip pat planuojame sukurti tinklaraštį.

- Pranešimas apie klaidą: Jei naudodamiesi svetaine pamatėte klaidos pranešimą arba susidūrėte su problema, sukurkite [pranešimą apie klaidą](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Funkcijos pasiūlymas: Jei turite idėją arba trūksta kažko, kas padarytų kūrimą lengvesnį ir patikimesnį, pateikite [funkcijos pasiūlymą](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Nežinote, nuo ko pradėti? Prisijunkite prie mūsų Discord serverio, ir mes padėsime jums pradėti!
