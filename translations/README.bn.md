## অবদান রাখা

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas ওয়েবসাইটটি একটি ওপেন-সোর্স প্রজেক্ট। আমরা সম্পূর্ণ স্বচ্ছ ডেভেলপমেন্ট প্রক্রিয়ায় প্রতিশ্রুতিবদ্ধ এবং যেকোনো অবদানকে অত্যন্ত মূল্য দিই। আপনি বাগ ঠিক করতে সাহায্য করুন, নতুন ফিচার প্রস্তাব করুন, আমাদের ডকুমেন্টেশন উন্নত করুন, অথবা এই প্রজেক্টের কথা ছড়িয়ে দিন—যেভাবেই হোক, আমরা আপনাকে Java Amazonas কমিউনিটির অংশ হিসেবে পেতে চাই। ভবিষ্যতে একটি ব্লগ তৈরি করারও পরিকল্পনা আমাদের রয়েছে।

- বাগ রিপোর্ট: সাইট ব্যবহারের সময় যদি কোনো ত্রুটির বার্তা দেখতে পান বা সমস্যায় পড়েন, তাহলে একটি [বাগ রিপোর্ট তৈরি করুন](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- ফিচার অনুরোধ: আপনার কোনো আইডিয়া থাকলে বা এমন কিছুর অভাব থাকলে যা ডেভেলপমেন্টকে সহজ ও শক্তিশালী করবে, তাহলে একটি [ফিচার অনুরোধ জমা দিন](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

কোথা থেকে শুরু করবেন বুঝতে পারছেন না? আমাদের Discord-এ যোগ দিন, আমরা আপনাকে শুরু করতে সাহায্য করব!
