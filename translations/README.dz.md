## المساهمة

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web هو مشروع مفتوح السورس. راهنا ملتزمين بمسار تطوير شفاف بزاف و نقدّرو بزاف أي مساهمة تجينا. سواء كنت تعاوننا نصلحو البقات (bugs)، ولا تقترح ميزات جداد، ولا تحسّن التوثيق ديالنا، ولا تهضر علينا للناس، يفرحنا بزاف نشوفوك جزء من جماعة Java Amazonas. عندنا الفكرة نديرو بلوغ (blog) في المستقبل.

- بلاغ على بق: إلا شفت رسالة خطأ ولا صادفتك مشكلة و راك تستعمل الموقع، دير [بلاغ على بق](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- طلب ميزة: إلا عندك فكرة ولا ناقصة حاجة تخلي التطوير أسهل و أقوى، بعث [طلب ميزة](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

ماعندكش فكرة منين تبدا؟ انضم للـ Discord ديالنا و راح نعاونوك تبدا!
