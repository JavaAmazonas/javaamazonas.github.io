## సహకారం అందించడం

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas వెబ్‌సైట్ ఒక ఓపెన్ సోర్స్ ప్రాజెక్ట్. పూర్తిగా పారదర్శకమైన అభివృద్ధి ప్రక్రియకు మేము కట్టుబడి ఉన్నాము మరియు ఏ విధమైన సహకారాన్ని అయినా మేము ఎంతో విలువైనదిగా భావిస్తాము. మీరు బగ్‌లను సరిదిద్దడంలో సహాయం చేసినా, కొత్త ఫీచర్లను సూచించినా, మా డాక్యుమెంటేషన్‌ను మెరుగుపరిచినా, లేదా దీని గురించి ఇతరులకు తెలియజేసినా — మీరు Java Amazonas కమ్యూనిటీలో భాగం కావాలని మేము కోరుకుంటున్నాము. భవిష్యత్తులో ఒక బ్లాగ్‌ను కూడా ప్రారంభించాలని మేము ప్లాన్ చేస్తున్నాము.

- బగ్ రిపోర్ట్: సైట్‌ను ఉపయోగిస్తున్నప్పుడు మీకు ఏదైనా ఎర్రర్ మెసేజ్ కనిపిస్తే లేదా ఏదైనా సమస్య ఎదురైతే, ఒక [బగ్ రిపోర్ట్](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+) సృష్టించండి.

- ఫీచర్ రిక్వెస్ట్: అభివృద్ధిని సులభతరంగా మరియు మరింత పటిష్టంగా మార్చగల ఏదైనా ఆలోచన మీ దగ్గర ఉంటే లేదా ఏదైనా లోపం ఉందని మీకు అనిపిస్తే, ఒక [ఫీచర్ రిక్వెస్ట్](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml) సమర్పించండి.

ఎక్కడ నుండి మొదలుపెట్టాలో తెలియడం లేదా? మా Discord‌లో చేరండి, మేము మీకు సహాయం చేస్తాము!
