## Bijdragen

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web is een open-source project. We zetten ons in voor een volledig transparant ontwikkelproces en stellen elke bijdrage zeer op prijs. Of je ons nu helpt bugs op te lossen, nieuwe functies voorstelt, onze documentatie verbetert of gewoon het woord verspreidt: we zouden je graag als onderdeel van de Java Amazonas-gemeenschap verwelkomen. We zijn ook van plan om in de toekomst een blog op te zetten.

- Bugmelding: Als je een foutmelding ziet of tegen een probleem aanloopt tijdens het gebruik van de site, maak dan een [bugmelding](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Functieverzoek: Als je een idee hebt of iets mist waardoor de ontwikkeling makkelijker en robuuster zou worden, verstuur dan een [functieverzoek](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Weet je niet goed waar je moet beginnen? Sluit je aan bij onze Discord en we helpen je graag op weg!
