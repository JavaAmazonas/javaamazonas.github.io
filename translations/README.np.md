## योगदान

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas वेब एउटा खुला स्रोत (open-source) प्रोजेक्ट हो। हामी पूर्ण रूपमा पारदर्शी विकास प्रक्रियाप्रति प्रतिबद्ध छौं र कुनै पनि योगदानलाई अत्यन्त कदर गर्छौं। तपाईंले बग सच्याउन मद्दत गरे पनि, नयाँ फिचरहरू सुझाव दिए पनि, हाम्रो डकुमेन्टेसन सुधारे पनि, वा यस प्रोजेक्टको बारेमा अरूलाई जानकारी फैलाए पनि, हामी तपाईंलाई Java Amazonas समुदायको एक हिस्साको रूपमा पाउन धेरै खुसी हुनेछौं। हामीले भविष्यमा ब्लग पनि सुरु गर्ने योजना बनाइरहेका छौं।

- बग रिपोर्ट: यदि तपाईंले साइट प्रयोग गर्दा कुनै त्रुटि सन्देश देख्नुभयो वा कुनै समस्या भेट्नुभयो भने, कृपया [बग रिपोर्ट पेश गर्नुहोस्](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- फिचर अनुरोध: यदि तपाईंसँग कुनै विचार छ वा विकासलाई थप सजिलो र बलियो बनाउने कुनै कुरा छुटेको छ भने, कृपया [फिचर अनुरोध पेश गर्नुहोस्](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

कहाँबाट सुरु गर्ने भन्ने थाहा छैन? हाम्रो Discord मा सामेल हुनुहोस्, हामी तपाईंलाई सुरु गर्न मद्दत गर्नेछौं!
