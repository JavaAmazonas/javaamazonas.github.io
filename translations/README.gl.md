## Como contribuír

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas web é un proxecto de código aberto. Estamos comprometidos cun proceso de desenvolvemento totalmente transparente e agradecemos moitísimo calquera contribución. Tanto se nos axudas a corrixir erros, propós novas funcionalidades, melloras a nosa documentación ou simplemente falas do proxecto a outras persoas, encantaríanos que formases parte da comunidade Java Amazonas. Ademais, temos previsto crear un blog no futuro.

- Informe de erro: Se ves unha mensaxe de erro ou atopas algún problema mentres usas o sitio, crea un [informe de erro](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Solicitude de funcionalidade: Se tes unha idea ou boto en falta algo que faría o desenvolvemento máis doado e robusto, envía unha [solicitude de funcionalidade](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Non sabes por onde empezar? Únete ao noso Discord e axudarémosche a comezar!
