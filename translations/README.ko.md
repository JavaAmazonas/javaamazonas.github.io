## 기여하기

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas 웹사이트는 오픈소스 프로젝트입니다. 저희는 완전히 투명한 개발 과정을 지향하며, 어떤 형태의 기여든 진심으로 감사하게 생각합니다. 버그 수정을 도와주시든, 새로운 기능을 제안해 주시든, 문서를 개선해 주시든, 혹은 프로젝트를 널리 알려 주시든, 여러분을 Java Amazonas 커뮤니티의 일원으로 맞이하고 싶습니다. 앞으로 블로그를 개설할 계획도 가지고 있습니다.

- 버그 리포트: 사이트를 이용하는 도중 오류 메시지를 보거나 문제를 겪으셨다면, [버그 리포트를 작성해 주세요](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- 기능 요청: 개발을 더 쉽고 견고하게 만들어 줄 아이디어가 있거나 부족한 부분이 있다면, [기능 요청을 제출해 주세요](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

어디서부터 시작해야 할지 모르시겠나요? 저희 Discord에 참여해 주세요. 시작하실 수 있도록 도와드리겠습니다!
