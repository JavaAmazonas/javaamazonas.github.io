## Придонес

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas веб е проект со отворен код. Посветени сме на целосно транспарентен процес на развој и високо го цениме секој придонес. Без разлика дали ни помагате да поправиме грешки, предлагате нови функции, ја подобрувате нашата документација или го ширите гласот за проектот, ќе ни биде мило да ве имаме како дел од заедницата Java Amazonas. Исто така, планираме во иднина да создадеме и блог.

- Пријава за грешка: Ако наидете на порака за грешка или на проблем додека го користите сајтот, отворете [пријава за грешка](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Барање за нова функција: Ако имате идеја или недостасува нешто што би го олеснило и зацврстило развојот, поднесете [барање за функција](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Не сте сигурни од каде да започнете? Придружете се на нашиот Discord и ќе ви помогнеме да започнете!
