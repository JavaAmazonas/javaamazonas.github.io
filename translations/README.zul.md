## Ukuhlanganyela

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

I-Java Amazonas web iyiphrojekthi evulekile (open-source). Sizibophezele enqubweni yentuthuko esobala ngokuphelele futhi siyawuthanda kakhulu noma yimuphi umnikelo. Kungakhathaliseki ukuthi usisiza ukulungisa amaphutha, uphakamisa izici ezintsha, uthuthukisa amadokhumenti ethu, noma usakaza izindaba ngathi, singathanda ukuthi ube yingxenye yomphakathi wakwaJava Amazonas. Sesihlele nokwakha ibhulogi esikhathini esizayo.

- Umbiko Wesiphazamiso: Uma ubona umlayezo wephutha noma uhlangabezana nenkinga ngesikhathi usebenzisa isayithi, dala [umbiko wesiphazamiso](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Isicelo Sesici Esisha: Uma unombono noma kukhona okushodayo okungenza intuthuko ibe lula futhi iqine kakhudlwana, thumela [isicelo sesici esisha](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Awunaso isiqiniseko sokuthi uqale kuphi? Joyina i-Discord yethu futhi sizokusiza ukuthi uqale!
