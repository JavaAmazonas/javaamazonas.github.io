```
ng serve
```

Java Amazonas Website nye dɔwɔwɔ si ʋu hena amesiame (open-source). Míele klalo be míawɔ dɔ le mɔ vevie me tso gɔme yi nuwuwu, eye míekpɔa kpekpeɖeŋu ɖe sia ɖe si nàna la abe nu xɔasi ene. Ne èkpe ɖe mía ŋu be míaɖɔ vodadawo ɖo, ne èɖo susu yeye siwo awɔ dɔ la nanɔ bɔbɔe eye wòasẽ ŋu wu la ɖa, ne èna míaƒe agbalẽwo nanyo wu, alo ne èƒo nu tso mía ŋu na amewo bubu la, míalɔ̃ be nànye Java Amazonas Habɔbɔ ƒe hamevi.
