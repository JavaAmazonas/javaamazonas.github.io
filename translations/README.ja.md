## コントリビューション

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas のウェブサイトはオープンソースプロジェクトです。私たちは完全に透明な開発プロセスを大切にしており、どんな貢献も心から歓迎しています。バグの修正を手伝ってくれる場合でも、新しい機能を提案してくれる場合でも、ドキュメントを改善してくれる場合でも、あるいはこのプロジェクトを広めてくれる場合でも、あなたにJava Amazonasコミュニティの一員として加わっていただけたら嬉しいです。将来的にはブログの開設も計画しています。

- バグ報告: サイトの利用中にエラーメッセージが表示されたり問題が発生したりした場合は、[バグ報告を作成してください](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- 機能リクエスト: 開発をより簡単かつ堅牢にするアイデアがある場合、または不足している機能がある場合は、[機能リクエストを送信してください](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

何から始めればよいかわかりませんか? 私たちのDiscordに参加してください。始め方をサポートします!
