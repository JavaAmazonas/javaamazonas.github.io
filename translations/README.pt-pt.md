## Contribuir

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

O Java Amazonas web é um projeto de código aberto. Estamos comprometidos com um processo de desenvolvimento totalmente transparente e agradecemos imenso qualquer contribuição. Quer esteja a ajudar-nos a corrigir erros, a propor novas funcionalidades, a melhorar a nossa documentação ou a divulgar o projeto, gostaríamos muito de o ter como parte da comunidade Java Amazonas. Também planeamos criar um blogue no futuro.

- Relatório de Erro: Se vir uma mensagem de erro ou encontrar um problema ao utilizar o site, crie um [relatório de erro](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Pedido de Funcionalidade: Se tiver uma ideia ou achar que falta algo que tornaria o desenvolvimento mais fácil e robusto, submeta um [pedido de funcionalidade](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Não sabe por onde começar? Junte-se ao nosso Discord e ajudamo-lo a começar!
