## Ag Cur Le

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Is tionscadal foinse oscailte é Java Amazonas web. Táimid tiomanta do phróiseas forbartha atá go hiomlán trédhearcach agus is mór againn aon rannchuidiú a fhaighimid. Bíodh tú ag cuidiú linn fabhtanna a dheisiú, ag moladh gnéithe nua, ag feabhsú ár ndoiciméadú, nó ag scaipeadh an scéil fúinn, ba bhreá linn go mbeifeá mar chuid de phobal Java Amazonas. Táimid ag pleanáil freisin blag a chruthú amach anseo.

- Tuairisc Fabht: Má fheiceann tú teachtaireacht earráide nó má bhíonn fadhb agat agus tú ag baint úsáide as an suíomh, cruthaigh [tuairisc fabht](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Iarratas ar Ghné: Má tá smaoineamh agat nó má tá rud éigin in easnamh a dhéanfadh an fhorbairt níos éasca agus níos láidre, cuir isteach [iarratas ar ghné](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Níl tú cinnte cén áit le tosú? Bí linn ar Discord agus cabhróimid leat tosú!
