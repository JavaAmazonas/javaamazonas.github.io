## Hissa qo'shish

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas veb-sayti ochiq manbali loyihadir. Biz to'liq shaffof ishlab chiqish jarayoniga sodiqmiz va har qanday hissangizni yuqori baholaymiz. Xatolarni tuzatishda yordam bersangiz ham, yangi funksiyalar taklif qilsangiz ham, hujjatlarimizni yaxshilasangiz ham yoki shunchaki loyiha haqida gapirib yursangiz ham, sizni Java Amazonas hamjamiyatining a'zosi sifatida ko'rishdan mamnun bo'lamiz. Kelajakda blog yaratishni ham rejalashtirmoqdamiz.

- Xato haqida xabar: Saytdan foydalanishda xatolik xabarini ko'rsangiz yoki muammoga duch kelsangiz, [xato haqida xabar bering](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Yangi funksiya so'rovi: Sizda biror g'oya bo'lsa yoki rivojlanishni osonroq va mustahkamroq qiladigan biror narsa yetishmayotgan bo'lsa, [yangi funksiya so'rovini yuboring](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Qayerdan boshlashni bilmayapsizmi? Discord'imizga qo'shiling, biz sizga boshlashda yordam beramiz!
