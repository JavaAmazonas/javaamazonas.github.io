## مشارکت

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

وب‌سایت Java Amazonas یک پروژه متن‌باز است. ما متعهد به یک فرآیند توسعه کاملاً شفاف هستیم و از هرگونه مشارکتی بسیار قدردانی می‌کنیم. چه در رفع اشکالات به ما کمک کنید، چه ویژگی‌های جدیدی پیشنهاد دهید، چه مستندات ما را بهبود ببخشید یا صرفاً این پروژه را به دیگران معرفی کنید، خوشحال می‌شویم شما را در کنار خود در جامعه‌ی Java Amazonas داشته باشیم. همچنین قصد داریم در آینده یک وبلاگ نیز راه‌اندازی کنیم.

- گزارش اشکال: اگر هنگام استفاده از سایت با پیام خطا یا مشکلی مواجه شدید، لطفاً یک [گزارش اشکال ثبت کنید](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- درخواست ویژگی: اگر ایده‌ای دارید یا چیزی کم است که توسعه را آسان‌تر و کامل‌تر می‌کند، لطفاً یک [درخواست ویژگی ثبت کنید](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

نمی‌دانید از کجا شروع کنید؟ به دیسکورد ما بپیوندید تا در شروع کار کمکتان کنیم!
