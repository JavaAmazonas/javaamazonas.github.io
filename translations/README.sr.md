## Доприноси

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Java Amazonas веб-сајт је пројекат отвореног кода. Посвећени смо потпуно транспарентном процесу развоја и веома ценимо сваки допринос. Без обзира да ли нам помажете у исправљању грешака, предлажете нове функционалности, побољшавате нашу документацију или ширите глас о нама, волели бисмо да вас имамо као део Java Amazonas заједнице. Такође планирамо да у будућности покренемо блог.

- Пријава грешке: Ако наиђете на поруку о грешци или проблем приликом коришћења сајта, отворите [пријаву грешке](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Захтев за функционалност: Ако имате идеју или сматрате да нешто недостаје што би развој учинило лакшим и стабилнијим, пошаљите [захтев за функционалност](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Нисте сигурни одакле да почнете? Придружите се нашем Discord-у и помоћи ћемо вам да кренете!
