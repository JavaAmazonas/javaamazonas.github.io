## Pag-ambag

```
git clone https://github.com/JavaAmazonas/java-amazonas.git
```

```
npm install
```

```
ng serve
```

Ang Java Amazonas web ay isang open-source na proyekto. Nakatuon kami sa isang lubos na transparent na proseso ng pag-develop at lubos naming pinahahalagahan ang anumang kontribusyon. Kung tumutulong ka man sa pag-aayos ng mga bug, nagmumungkahi ng mga bagong feature, nagpapahusay ng aming dokumentasyon, o kaya naman ay ikinakalat lang ang balita tungkol dito, ikagagalak naming maging bahagi ka ng komunidad ng Java Amazonas. Plano din naming gumawa ng blog sa hinaharap.

- Ulat ng Bug: Kung may nakita kang error message o naranasan mong problema habang ginagamit ang site, gumawa ng [ulat ng bug](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+bug&template=bug.yaml&title=%F0%9F%90%9B+Bug+Report%3A+).

- Kahilingan para sa Feature: Kung mayroon kang ideya o may nararamdaman kang kulang na makakatulong para maging mas madali at matatag ang pag-develop, magsumite ng [kahilingan para sa feature](https://github.com/JavaAmazonas/java-amazonas/issues/new?assignees=&labels=type%3A+feature+request&template=feature.yml).

Hindi sigurado kung saan magsisimula? Sumali sa aming Discord at tutulungan ka naming makapagsimula!
